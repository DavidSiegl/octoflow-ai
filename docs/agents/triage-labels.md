# Triage Labels

The skills speak in terms of five canonical triage roles. In this repo's tracker (`docs/agents/issue-tracker.md`) a
role is the `Status:` value of the same name, verbatim: the table and what each value means are in the
`scratch-issue-tracker` skill, under "Triage labels". ticket-sync applies the same string as the GitHub issue's label.

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), write that role's `Status:` value.
