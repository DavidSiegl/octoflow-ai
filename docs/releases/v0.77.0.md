## Closed runs leave the app's overview

- **The overview leaves closed runs out.** After "Clean up runs…" closes them, they go from the list as their
  records arrive. "Show closed runs (N)" above the overview, there while some run is closed and unchecked each time
  a project opens, lists them again, as before. With every run closed, the overview says "No open runs.". Nothing
  is deleted: `list` and `show` still show closed runs.
