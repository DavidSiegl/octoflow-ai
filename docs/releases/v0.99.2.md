## The app shows the model a role's agent ran on

When a run's harness doesn't offer a role's model, as claude doesn't offer every model name, its agent starts on a
model of its own. The app still showed the model the role asked for, so a run on `claude-haiku-5-5` looked cheaper
than it was. Each turn now records the model its agent ran on: the one the session names, or none when it names none.
The run map, the turn feed and the status line show that model, marked with the one that was not offered, and
hovering it shows why, in `run.log`'s words. That line now names the model taken: `claude offers no model
claude-haiku-5-5; starting it on claude-opus-5-5`.

The role's model is kept, so the role's next agent asks for it again. `summary.md`, the pull request body and
`metrics.json`'s roles still name the model the role asked for. Runs in herdr are unchanged.
