## The secret scan's limit on binary files is documented

Nothing the orchestrator or the desktop app does changes. The pre-push secret scan never read a change git shows as
"Binary files ... differ", and still does not. No rule in `.gitleaks.toml` reaches one, not even a path rule, so a
secret in it, a `.p12` keystore say, is pushed unreported. The README's requirements say which changes git shows so;
keep secrets out of them.
