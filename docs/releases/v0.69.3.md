## A step's prompt is read from the run, not from a running workflow

- **Every prompt is word for word what 0.69.2 sends**: a step's first and later turns, a fresh session's, the quality,
  locks and proofs notes, and the BLOCKED note. Nothing a user sees or saves changes; this release moves how the engine
  builds them, so that a later change can show a step's prompt without running the step.
