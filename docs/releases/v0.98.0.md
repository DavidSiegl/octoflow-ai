## `--timeout 0` means no turn limit, for `run` and `resume` alike

`run --timeout 0` used to fall back to the default of 1800 seconds, while `resume --timeout 0` saved 0 and every
turn then timed out at once. Now `--timeout 0`, or any value below 0, means a Builder or Reviewer turn has no time
limit, for both commands; idle notices are still sent. A run saved by an older `resume --timeout 0` resumes with no
limit. In a run with the quality gate, the Builder of a turn without a limit, under `--timeout 0` or in a step paced
by a human, is still told that the orchestrator runs the gate after its report, without a time limit. A workflow can
reword that note in a new prompt file, `QUALITY_FOLLOWS_NO_LIMIT_NOTE.md`; `QUALITY_FOLLOWS_NOTE.md` keeps its text
and still words the note for a turn with a limit.
