## A Ctrl-C keeps the tokens of the prompt an ACP agent was answering

An ACP run stopped with Ctrl-C, or with the app's stop, killed its agents at once, so the prompt one of them was still
answering never recorded the tokens its answer carries, and the turn could count "unknown" tokens after a resume. The
run now cancels what its agents have pending and gives them two seconds to answer before it kills them. An agent that
does not answer by then is killed as before.
