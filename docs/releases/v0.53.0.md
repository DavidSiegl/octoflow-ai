## A setup dialog in the desktop app

The desktop app checks what a run of the open project needs, the same checks `orchestrator doctor` makes, and shows
each one that failed with its fix:

- **On first use** it opens by itself, and goes on opening at each start until it has been closed with every check
  needed for any run passed.
- **"Check setup…"** in the project bar opens it for the open project at any time.

Reaching herdr from a herdr pane is not needed here, since the app starts no run: it shows as a warning.
