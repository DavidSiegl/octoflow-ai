## Pull request links open in the browser

In the desktop app, a run's pull request link, in the overview and in the run's detail, opens the pull request in
your browser. These were plain web links, which the app's window could not hand to a browser, so a packaged app
likely did nothing on a click. A click on the overview's link no longer also opens the run's detail.

The links leave the app the way About's do, through the app's own opener run in your shell's environment, which
opens only `https` pages and the license files the app bundles.
