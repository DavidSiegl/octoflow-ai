## The agents are told to look at the whole change under `diff.relative` and `status.showUntrackedFiles`

- **A Reviewer, or any other step, run in a subdirectory of the repository now sees every file of the change.** The
  prompts told each agent to run `git diff <base>`. With `diff.relative = true` in the user's git config, that lists
  only the files under the agent's directory, so a Reviewer could approve a change without seeing an edit elsewhere,
  such as a weakened test. The prompts now name `git diff --no-relative <base>`, which covers the whole repository
  whatever the setting.
- **The agents also see the new files, whatever `status.showUntrackedFiles` says.** The prompts sent them to
  `git status --porcelain` for the files not yet tracked, which lists none with `status.showUntrackedFiles = no`, so a
  new file went unreviewed. They now name `git status --porcelain --untracked-files=all`, which lists every new file,
  also those in a new directory, one by one.
