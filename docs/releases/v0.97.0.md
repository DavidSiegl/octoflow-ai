## An agent waiting on something outside the run no longer runs out its turn

An agent that had to wait for something outside the run, such as another pull request merging, could not say so:
its turn's time limit ran on through the wait, the human was told it had stalled, and the run failed once the limit
passed. Every prompt of a step that can block now says how to report a wait: the agent writes what it waits on to a
`.waiting` file beside its report and deletes the file when it goes back to work. While that file stands, the turn's
time limit stands still and no stall is reported; the human is told once at the start of each wait. A resumed run
waits as well, and an agent that exits while waiting still fails the run. Turn records, `summary.md` and the desktop
app do not show waits yet: a turn's time there includes them.
