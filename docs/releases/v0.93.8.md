## The quality gate is octoflow-gate 0.15.3

The octoflow-gate release this octoflow is built with is 0.15.3, in place of 0.15.2. It judges a project whose
`ci/gate.pin` is missing; a project that pins a release of its own, as `doctor --setup-gate --pin-gate` does, keeps it.
What the gate changed: the release notes of [0.15.3](https://github.com/DavidSiegl/octoflow-gate/releases/tag/v0.15.3).
