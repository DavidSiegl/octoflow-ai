## A run no longer starts from a closed run's branch that origin does not have

A run started in a checkout left on the branch of a closed run, as `close` leaves an in-place run's checkout, took
that branch as its base even when the run had failed before publishing it, and then failed fetching it with git's
`couldn't find remote ref`. It now asks `origin` first and stops before the interview, naming that run and saying to
check out its base branch. A closed run's branch that `origin` has still starts, as before.
