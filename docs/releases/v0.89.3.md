## Stopping the macOS desktop build leaves no mounted .dmg

`packaging/build-desktop.sh` now cleans up after the `.dmg`'s smoke test the way it does after the AppImage's. If
the script is stopped during that test, by a Ctrl-C, SIGHUP or SIGTERM, it detaches the `.dmg` and then removes the
directory the volume was mounted in. Before, the volume could stay mounted and the directory stay behind. Releases
themselves are unchanged.
