## The last of the Python imitations gone

The orchestrator no longer reads or writes anything the way Python did. What you may notice:

- **Hints name the program you ran.** The command that resumes a run, in `list`, `show`, `list --json`, serve's run
  records and the note after a Ctrl-C, and the hint under `workflows`, start with the name you invoked the
  orchestrator by, `orchestrator resume a1b2c3`, where they said `orchestrator.py`; so does the usage a mistyped
  command prints.
- **The new-dependencies check reads its manifests' values as TOML.** A source of a shape the check does not know is
  quoted as an inline TOML table, `{ mirror = { x = 1 } }`, also when it holds a date or a time, where such a
  manifest was unreadable before. A `[tool.uv.sources]` entry's `index` names only an index whose `name` is the same
  TOML value. A `[project] name` that is not a string is refused: `[project] name is not a string`.
- **`judged-in-quality`** trusts a quality build only when `ci/gate-rust/`, `rust-toolchain.toml` and `Cargo.lock`
  are unchanged too; it no longer looks at `orchestrator.py`.
