## The desktop app closes and forgets only the runs it shows

The desktop app's overview leaves out a run whose directory, or whose `state.json`, leads out of the project's runs
directory through a link. Closing or forgetting runs from the app, and the list of runs such a request would touch,
now leave those runs out too, so the app no longer closes or deletes a run it does not show.
`octoflow close` and `octoflow forget` from a shell act on every run as before.
