## A missing gitleaks is explained by what the run really scans

octoflow refuses to start a run that needs gitleaks when gitleaks is missing, and says why it is needed. A run with
the quality gate but no pull request was told "this run pushes, and every push is scanned for secrets first", though it
pushes nothing. It is now told that the quality gate scans each snapshot for secrets before it judges it. A run that
opens a pull request is still told about its pushes.
