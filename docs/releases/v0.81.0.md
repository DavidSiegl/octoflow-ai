## Closed runs can be forgotten

- **`forget` deletes a closed run's directory.** `orchestrator forget RUN` deletes the run directory of a run that
  `close` closed, so that `list`, `show` and the app no longer show it; `forget --all` does so for every closed run
  of the project, and `--dry-run` names the directories that would go and deletes nothing. A run that is not closed
  is refused by `forget RUN` and left by `--all`, and a directory that cannot be deleted does not stop `--all`, but
  makes it exit 1. `--machine` and `--cwd` work as for every command.
- **`metrics` keeps forgotten runs.** Before a run's directory goes, its `metrics.json` line is added to
  `.orchestrator/metrics-archive.jsonl`, which `metrics` reads too, so it prints the same lines before and after
  `forget`.
