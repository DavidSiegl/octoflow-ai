## Close every run you are done with in one command

- **`close --all`** closes every run of the project that `close` would: finished, failed and stale. Each loses what
  `close` takes from one run: its herdr workspace, its local refs, and for a failed or stale `--worktree` run its
  worktree, uncommitted changes included, and its branch when that holds no commit beyond the run's base. A running
  run, and one whose state this release does not read, is skipped with a line saying why; a run already closed is
  only counted. The sweep ends with a count of the runs closed, skipped and already closed.
- **One failing run does not stop the others.** Its error is printed with its run, the rest are still closed, and
  the exit status is 1. Running `close --all` again finishes what failed.
- **`--dry-run`**, for `close --all` and `close RUN`, prints what closing would do, the worktree's uncommitted files
  included, and the line that would be recorded, and changes nothing.
- Each run is read again just before it is closed, so a run resumed while the sweep goes on is skipped, not closed.
  Ctrl-C starts no further run; one it stops part way is finished by the next `close --all`. Run directories stay,
  so `list` and `show` still show closed runs.
- `close` without a run is a usage error, as before; give it a run or `--all`, not both.
