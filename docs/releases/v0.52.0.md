## Placeholders are names alone

A placeholder in a workflow file's prompts, `file` and `proof_command`, or in a prompt file, is now `{name}` and
nothing more: a conversion (`{task!r}`), a format spec (`{task:>10}`), an attribute (`{diff.upper}`), an index
(`{diff[0]}`) or a positional field (`{}`, `{0}`) is refused when the file is read, naming the placeholder and its line
and column. Write a literal brace as `{{` or `}}`, as before.

**Runs from earlier releases.** A run whose saved workflow or prompt files use such a placeholder is refused when you
resume it, naming the placeholder: finish it with the release that started it, or close it.
