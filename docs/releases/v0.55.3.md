## A finished run's last files reach the desktop app

- **serve's event stream now shows a finished run's `summary.md` and `metrics.json`.** A run is finished by the save
  that clears its owner, and the engine writes those files just after it. A poll that landed in between kept the
  run's file list without them, and the stream never listed the run's files again unless its record changed, so the
  desktop app did not show them. A finished run's files are now listed on each poll until two polls in a row find
  the same list, and again whenever its record changes. Files written more than one poll interval (1 s for a local
  project, 5 s for a remote one) after that save still show only at the record's next change.
