## The AppImage build cleans up after itself, and the README warns about running without FUSE

- **The README says what running the AppImage without FUSE costs:** with `APPIMAGE_EXTRACT_AND_RUN=1` or
  `--appimage-extract-and-run` it extracts itself into `$TMPDIR` (`/tmp` by default) on every run and leaves it
  there, about 340 MB for each version. Install FUSE (`libfuse2`), or extract it once with `--appimage-extract` and
  run the `squashfs-root/AppRun` that makes.

For those building Octoflow AI: `packaging/build-desktop.sh` no longer leaves `appimage_extracted_*` directories in
the caller's `TMPDIR`. linuxdeploy and appimagetool, AppImages themselves, extract into the script's own
`build/desktop/tmp`, and the smoke test's directory, where the desktop AppImage extracts, is removed with it, on
success, on a failure, and on Ctrl-C, SIGHUP or SIGTERM, after which the script dies of that signal. One a `kill -9`
leaves in `build/desktop/tmp` is removed by the next build.
