## The configuration directory is octoflow-ai

- **Workflow files, prompt files and the app's setup marker now live in `~/.config/octoflow-ai`**, or
  `$XDG_CONFIG_HOME/octoflow-ai` when that variable is set, after the product's name.
- **`~/.config/ai-agents-orchestrator` is no longer read.** Its workflows and prompt files go unfound and the
  desktop app's setup dialog opens again until you move it:

  ```sh
  mv ~/.config/ai-agents-orchestrator ~/.config/octoflow-ai
  ```

  or, with `XDG_CONFIG_HOME` set, `mv "$XDG_CONFIG_HOME/ai-agents-orchestrator" "$XDG_CONFIG_HOME/octoflow-ai"`.
  Runs already started are not affected: a run keeps its workflow and prompts in its own state.
