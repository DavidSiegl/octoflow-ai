## The app resumes its runs, and the CLI keeps out of them (behind the developer switch)

With `OCTOFLOW_APP_BACKEND=acp` in serve's environment, a hidden developer setting, a run the app started over ACP
that stopped, failed or lost its orchestrator shows a Resume button in its detail. Resume ends any agent the run
left running, then resumes the run in the background, each agent continuing its saved session. Run records gain
`resumable`, and serve gains `POST /resume`.

The CLI's `close`, `forget`, `refresh` and `resume` refuse such a run, naming the app, and their `--all` sweeps skip
it; `list` and `show` still show it, without a resume command. The app's Clean up stops a running app run before it
closes it, and ends the agents a crashed one left. Without the setting nothing changes.
