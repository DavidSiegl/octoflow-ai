## drain holds what it cannot run for you instead of stopping, waiting or skipping it

`octoflow drain` handles the edge cases of a ticketed queue:

- `--dry-run` names each ticket and spec it would hold for you, and exits as the real drain would: 1 when something is
  held, where it exited 0 before.
- A `Blocked by:` line names a ticket by its whole file name or by its number, so `02-old-name` no longer matches every
  ticket numbered 02. Notes in parentheses are dropped before the line is split, `none` means no blocker only when it
  stands alone, and `- 03` or `none yet, 03` now wait for 03.
- A spec blocked by a `wontfix` spec, or with a ticket drain cannot read, is held for you with its tickets, while the
  rest of the queue drains on. Before, a spec blocked by a `wontfix` one waited forever, and an unreadable ticket
  stopped the whole drain.
- A ticket's stale `Run:` line under a held spec no longer stops the drain.
- A spec whose `spec.md` is deleted mid-drain is reported gone, rather than the drain saying all specs cleared.
- A ticketed spec turns `done` when its last ticket merges, whatever its status said.
