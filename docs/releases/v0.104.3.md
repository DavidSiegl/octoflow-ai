## A resumed agent keeps the model it took when its session no longer says

When an ACP harness did not offer a role's model, the run named the one the agent ran on instead: "sonnet (opus not
offered)". If that agent exited and a resume reopened its session, and the session's answer listed no models, the run
forgot the substitute. summary.md, the `Octoflow-Role` trailer, metrics.json's `roles` and the next turn then named
opus. The agent's record now keeps the substitute through such a reopening. A fresh session, or one that lists its
models, replaces it as before.
