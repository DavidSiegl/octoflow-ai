## A resumed agent keeps the model it took when its session no longer says

When an ACP harness did not offer a role's model, the run named the one the agent ran on instead: "sonnet (opus not
offered)". If that agent exited and a resume reopened its session, and the session's answer named no model, neither
the one it runs on nor a list, the run forgot the substitute. summary.md, the `Octoflow-Role` trailer, metrics.json's
`roles` and the next turn then named opus. The agent's record now keeps the substitute through such a reopening while
the resume asks for the same model. A fresh session, a reopened one that names the model it runs on or lists its
models, or a resume that asks the role for another model, replaces it as before.
