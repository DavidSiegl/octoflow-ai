## A design workflow, built in

- **`--workflow design` is for visual work**: a web page or frontend, a logo or icon set, a mockup, a small design
  system. A Creative Director agrees a brief with you: audience, deliverables with their formats, sizes and paths,
  brand constraints, tone, accessibility level. A Designer makes two or three concepts that differ in kind, and the
  Creative Director walks you through them so you can pick a direction. The Designer then builds it, and a Design
  Critic renders the work itself and judges it against the brief and your pick. Once the Critic approves, the
  Creative Director shows you the result and records your verdict; changes you ask for go back to the Designer.
  You are asked three times: at the brief, the direction and the acceptance, each in the Creative Director's pane,
  with no timeout. A run given its brief with `--spec`, or by `drain`, skips only the brief: it still waits for you
  at the direction and the acceptance.

  `--max-rounds` (3 by default) counts the Critic's and your acceptance's rounds together. In the last round the
  run publishes whatever the verdict: if the Critic still asks for changes there, you are not asked, and changes
  you ask for there are recorded in the run but not made. Raise `--max-rounds` for work you expect to send back
  more than once.

  The agents render with what your machine has: a headless Chromium or Chrome, or the project's Playwright, for a
  page, and `rsvg-convert` or ImageMagick for an SVG. They install none of these and say so when none is there.
  Screenshots stay in the run's directory, and the concepts not taken are deleted before the change is published.
  `octoflow workflows design` prints the workflow as a file to start a variant of your own from.

- **A workflow file named `design.toml` no longer loads.** As with `quick` and `product-team` in 0.85.0, a file
  cannot take a built-in workflow's name. If you have a `design.toml` in `~/.config/octoflow-ai/workflows/`,
  `octoflow workflows` lists it with an error, and `--workflow design` runs the built-in. Rename the file (say
  `my-design.toml`) to keep your workflow and run it as `--workflow my-design`.
