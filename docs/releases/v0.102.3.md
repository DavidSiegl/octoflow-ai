## The app's forget no longer archives a metrics.json from outside the run

When the desktop app forgets a run, the run's `metrics.json` is added to the project's metrics archive before its
directory is removed. A `metrics.json` that was a symbolic link to a file outside the run directory had that file
archived. The app now leaves such a file out, archiving nothing for the run, and still forgets the run.
`octoflow forget` follows links as before.
