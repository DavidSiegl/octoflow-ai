## An agent's pane holds still while you read further up

The desktop app shows the last 200 lines of an agent running in herdr, read again every few seconds. Once the agent
had printed more than that, each read dropped lines off the top, so the line you had scrolled up to read crept away.
While you are scrolled up from the end, the pane now keeps the text it shows and says "Held while you are scrolled up:
scroll to the end for newer output." Scrolled back to the end, or after you send the agent input, it shows the newest
text and follows it again.
