## A check of the engine's Jenkins client against the real Jenkins

Nothing the orchestrator or the desktop app does changes. For those working on Octoflow AI:

- **`cargo xtask contract`** makes each call a quality round makes against the real quality job, through the engine's
  own Jenkins client, and checks what the client reads of each answer, and the JSON answers' raw fields, against
  what the tests' fake Jenkins gives. It triggers
  one real build of `main`, so it is run by hand: before a release that changes `engine/src/ci.rs` or
  `engine/src/http.rs`, and after a Jenkins upgrade (docs/quality-gate.md, "The calls"). Its last line says whether a
  quality round could have taken the build within `QUALITY_TIMEOUT`.
- It replaces the Python engine's contract test, which went with that engine. This release exists because the check
  makes the chores' crate depend on the engine's, which changes `Cargo.lock`.
