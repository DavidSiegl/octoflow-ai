## The Antigravity CLI replaces Gemini CLI as a harness

- **`--agent agy` runs a role in Google's Antigravity CLI**, herdr's `agy` kind. `--permission-mode` becomes nothing
  for `default`, `--mode accept-edits` for `acceptEdits`, `--dangerously-skip-permissions` for `bypassPermissions`
  and `--mode plan` for `plan`; an exited agent resumes with `--conversation <id>`, and a `--worktree` run's agy is
  granted the run directory with `--add-dir`. Its turns' tokens are `unknown`: it records them in a form the engine
  does not read.
- **`gemini` is gone.** herdr installs no `gemini` integration any more, only `antigravity-cli`. `--agent gemini`
  is a usage error; a workflow file or a saved run that names `gemini` is refused, saying that agy replaced it. Name
  `agy` in its place, and resume the saved run with `--agent agy` or `--role-agent ROLE=agy`.
- **`doctor` checks each harness's own herdr integration**, `antigravity-cli` for agy, and its fix names it:
  `herdr integration install antigravity-cli`.
