## A worktree run with nothing to publish no longer leaves an empty worktree behind

A `--worktree` run that ended approved without changing anything git tracks kept its worktree, detached, even when
nothing was in it, and no command removed it later. Such a run now removes its worktree when `git status --ignored`
lists nothing there. A worktree that holds a file, if only an ignored one, is still kept, detached, as before.
