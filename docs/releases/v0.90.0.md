## The quality gate is octoflow-gate 0.15.2

The octoflow-gate release this octoflow is built with is 0.15.2, in place of 0.10.0. It judges a project whose
`ci/gate.pin` is missing, and `doctor --setup-gate` pins it in a project it sets up; a project that pins a release of
its own keeps it. What the gate changed: its release notes from
[0.11.0](https://github.com/DavidSiegl/octoflow-gate/releases/tag/v0.11.0) to
[0.15.2](https://github.com/DavidSiegl/octoflow-gate/releases/tag/v0.15.2).
