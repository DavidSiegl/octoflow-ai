## The .deb installs Tab completion

Installing the `.deb` now turns on Tab completion of `octoflow` in bash, zsh and fish, with no line in your shell's
startup file: the package puts the completion scripts where each shell looks for them. bash needs the
`bash-completion` package for it. A line you added for 0.95.0 (`source <(OCTOFLOW_COMPLETE=bash octoflow)` or its
zsh and fish forms) still works and can be removed. The AppImage installs none.
