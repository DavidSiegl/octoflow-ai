## Commands leave a run an earlier release saved to that release

- **`close`, `prune`, `refresh` and `drain` skip a run whose `state.json` this release cannot read**, one saved by
  a release before the current state format, or one whose fields do not read, and say why: finish or close it with
  the release that saved it. Before, `close`, `prune` and `refresh` acted on such a run by the keys they found in it.
  `close` and `refresh` given that run by name fail with the same words; `list` and `show` still show it, with why.
- **A run saved as `done` whose orchestrator is still ending it counts as running everywhere.** `prune` no longer
  deletes its branch, `list` shows it as `running`, and a run that starts or resumes in its checkout stops, as beside
  any running run. One whose orchestrator died while ending it is `stale` in `list`, with its `resume` command.
