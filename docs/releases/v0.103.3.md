## prune keeps a branch another run builds on

A run started on a closed run's branch takes it as its base, and its pull request targets that branch on `origin`.
`octoflow prune`, and the sweep a run makes before it opens its pull request, deleted that branch on `origin` once
its own pull request was merged, and GitHub then closed the new run's pull request. Prune now leaves such a run's
branch, local and on `origin`, and its worktree, alone while a run that is not closed records the branch as its base,
and says which run; `forget` keeps the run until then. Once that run is closed, prune decides the branch as before:
deleted when nothing was added to it, kept when the later run's pull request was merged into it.
