## show and the desktop app say when a run had nothing to publish

A run that succeeded without changing anything git tracks opens no pull request. Only summary.md said why; `show`
and the desktop app showed no pull request, the same as for a run that never got to open one. Now `show` prints the
reason on its `pr` line, the app's run view says it where the pull request link would be and its map's publish
station reads "nothing to publish", and `list --json` and the app's run records carry `nothing_to_publish`, true for
such a run.
