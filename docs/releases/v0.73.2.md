## The engine's messages are worded in its own style

Exit codes, flags, JSON keys and saved state stay as they are; only the words change.

- **A run that ends without a verdict** ends the program's output with `NO_VERDICT: <path>`, where it printed
  `None: <path>`; a script that reads the last line sees this word in place of a verdict. Its desktop notification
  says "Run finished without a verdict", not "Run finished: None".
- **A system error** names its path first and leaves out the error number: `/x/spec.md: No such file or directory`,
  where it said `[Errno 2] No such file or directory: "/x/spec.md"`. A path holding a space or a control character
  is quoted. A request PyPI or crates.io did not answer says `Connection refused` or the resolver's words without
  `[Errno N]` too.
- **A command that ran out of time** is named as the shell line that runs it, `` `<command>` timed out after N
  seconds ``, where it was named as a quoted list of its words.
- **`resume --spec` and `drain --spec`** say `unexpected argument '--spec' found`, as the command line's other
  usage errors word an argument a command does not take, where they said `unrecognized arguments: --spec`.
- **serve answers a method it does not serve** with a 501 whose body is `{"error": "unsupported method \"PUT\""}`, as
  it answers its other errors, where it sent an HTML error page.
- **Texts that said `None` for something missing** say what is missing: drain's change line for a spec without a
  Status: line reads `no status ->`; a run's owner without a pid or host shows `unknown` for it in `list` and in the
  takeover error; `prune` says a pull request closed without a closing time is closed "without a closing time"; a
  run directory whose age is not a number is "an age that is not a whole number"; a state.json that is not a JSON
  object is "array where an object belongs" (or whichever JSON type it is).
- **A run whose state records conflicts but no base branch**, which only a hand-edited state.json has, is refused by
  `refresh` with that reason, where its pull request body would have been searched for a warning naming `None`.
