## A run no longer starts from another run's branch

A run started in a checkout left on the branch of another run that is not closed, as a failed in-place run leaves
it, used to take that branch as its base and failed at once, unable to fetch a branch origin never had, naming
neither run. It now stops before the interview and names that run: if the run is idle, check out the base branch
it names, and close the run when you are done with it; if it is running, wait for it to end. A `--worktree` run
checks the same. `resume` is unchanged.
