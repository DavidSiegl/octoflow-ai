## close finds a run's workspace where the run started it

A run saves which of this machine's herdr servers it started its agents in; the desktop app starts its runs in its
own herdr session, `octoflow`. `close` looked the run's workspace up in the server of the herdr pane it ran from
instead. So closing an app-started run from a pane of your own herdr session said "workspace already gone" and left
the workspace open.

- **`close` and `close --all` check and close a run's workspace in the herdr server the run saved**, as the app's
  console already reaches its agents there. A run that saved no server (one on a herdr machine, or one whose server
  could not be told) is looked for where it was before. A saved server that is no longer running, such as the app's
  after a reboot, holds no workspace: the run closes with "workspace already gone", as it did before. What `close` prints and its exit
  status are unchanged.
