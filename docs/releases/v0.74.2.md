## new-dependencies points each finding at its own entry

A package added from two sources in one manifest, such as `foo = "1"` and `foo = { git = ".." }` in one
`Cargo.toml`, gave two findings that both pointed at the first added line naming the package.

- **Each finding names the line of its own entry**, read from the manifest's TOML, so the two sources above give
  findings on two lines.
- **A lock file's findings point at the package's `[[package]]` line.**
