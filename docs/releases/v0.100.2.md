## The run view no longer re-renders every second

The app's clock re-rendered the whole run detail once a second: the octopus, the handoff file's Markdown and the
agent's conversation, though only two lines in it show an age. With a long handoff file or conversation each tick
took long enough to drop the octopus's animation frames, so it stuttered. Now only the lines that show an age, the
run's status and the octopus's line on what runs now, and the overview's table, update with the clock.
