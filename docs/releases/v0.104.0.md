## A turn's time says how much of it the agent waited on something outside the run

An agent that reports a wait on something outside the run, such as another pull request's merge, had that wait
counted as its own time, and only the human's notice and the run's log said it was waiting. Each turn now records the
seconds of those waits as `outside_wait_seconds` in `state.json` and `metrics.json`, and `summary.md` and the pull
request's "Run timings" show them apart from the permission waits: "12m 03s (3m 19s waiting for you, 6m 00s waiting
outside the run)". The permission waits, shown as "waiting" before, now read "waiting for you".

While such a wait stands, the turn's record carries it as `waiting_on`, what the agent waits on and since when, and the
desktop app's run view says so on the running turn: "build · claude · running 19m · waiting 4m on the merge of pull
request #526".
