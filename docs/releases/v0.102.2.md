## A resumed pull-request run checks gitleaks before its next turn

A pull-request run checked that gitleaks is installed only before its interview. Resumed past that point after
gitleaks was removed, it spent its remaining turns and failed only when it came to publish. It now checks gitleaks at
every start, before its next turn, and stops there naming gitleaks. A run with the quality gate likewise checks
gitleaks and the gate's tools again when it is resumed, as long as its gate has a snapshot left to judge.
