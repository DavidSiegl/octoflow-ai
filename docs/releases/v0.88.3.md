## The engine's ordered tables are indexmap's

The engine's own insertion-ordered map (`crate::map::Map`) is replaced by `indexmap`'s `IndexMap`, a direct
dependency now, already in the build through serde_json and toml. state.json, the records and the output keep their
order and their content.

One message reads differently: a `state.json` whose `models`, `agents`, `next_harnesses`, `prompt_overrides` or
`locked` field holds something other than an object is refused as before, but the error now ends `expected a map`
where it ended `expected an object`. Workflow files are checked as before, with the same messages.
