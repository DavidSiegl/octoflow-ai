## Closing the app asks about its running runs (behind the developer switch)

With `OCTOFLOW_APP_BACKEND=acp` in serve's environment, a hidden developer setting, closing the app's window while
runs it started over ACP in the open project are running asks what to do with them: "Keep running" (the default),
which leaves them running without the app, or "Stop all", which stops each as Ctrl-C stops a CLI run: every pending
permission is answered cancelled, every agent's prompt cancelled, and the run is released as interrupted, for Resume
to continue. "Don't ask again" keeps the choice, and "Settings…" in the top bar, shown only with the developer
setting on, changes it. The choice is kept in the orchestrator's configuration directory, as `close-choice`. Runs in
herdr are never stopped, and with none of the app's runs running the window closes at once.

serve gains `POST /stop` and `/close-choice`.
