## `--version`, a clearer stop before a role starts, and `show` in your own time zone

- **`orchestrator --version` (or `-V`) prints the release, such as `orchestrator 0.61.0`.** There was no way to tell
  which release an installed binary is.
- **A role stopped before it starts says so.** When a harness asks something before it starts, most often Claude Code
  asking whether to trust a folder it has not run in, the run now says the role "needs your answer before it starts"
  and names that question in its log, instead of the "needs your answer" a question within a turn gets. The README's
  Requirements list that trust.
- **`show` prints turn starts in this machine's time zone** and names the zone in the heading, such as
  `turns, started in Europe/Vienna`. They were UTC without saying so, while a run id names its start in local time, so
  a turn could seem to start before its run. summary.md and the pull request's timings stay in UTC, as their header
  says.
- **The README says which `--permission-mode` lets a run go through unattended** (Harnesses, Unattended runs): Claude
  Code's `default` and `acceptEdits` stop for every shell command, such as running the tests.
