## A resumed run keeps a prompt override a newer release could still fill

- **A run that saved a prompt override is no longer refused on resume for leaving out a placeholder.** A resume
  checked the overrides a run started with by the rule for a prompt file: it must use every placeholder the built-in
  text has. So once a release gave a built-in prompt a new placeholder, every run that had saved an override of that
  prompt would have been refused ("finish the run with the release that started it"), though the override could still
  be filled in. A resume now refuses an override only for what cannot be filled in: a template that does not parse,
  or a placeholder the prompt does not offer. The run goes on with the text it chose. A prompt file you write today is
  still held to the full rule. 0.58.0 gave FIX_PROMPT `{findings}`, but a run started before it
  was checked against that earlier release's placeholders, so no run was affected so far.
