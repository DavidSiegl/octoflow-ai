## The desktop app's runs no longer depend on the AppImage's mount

Under the AppImage, the app started every run and resume from the program inside its FUSE mount, which goes away
when the app quits. A run that outlived the app kept going only on the part of the program it had already loaded:
the first step that needed more of it, such as a build round, the gate or the pull request, would crash with SIGBUS.
The app now starts its runs and resumes from the AppImage file itself, so each run has a mount of its own. The
`.deb`, the macOS app and an extracted AppImage start runs from the app's own program, as before.
