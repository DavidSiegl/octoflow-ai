## The close hint of a run refused on another run's branch names the command you would type

A run started in a checkout left on the branch of another run that is not closed stops and says to close that run
once done with it. The command it gave was always `octoflow close <key>`: it ignored the name the program was invoked
by and the `--machine` and `--cwd` the run was given, so for a project named that way the command looked in the wrong
place and found no such run. It now names the command as `resume`'s hint does, for example
`octoflow close <key> --machine box --cwd ~/proj`. For a run of the desktop app's, which the CLI does not close, it
says to close it from the app.
