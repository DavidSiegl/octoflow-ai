## quick and product-team are built in

- **`--workflow quick` and `--workflow product-team` run with no file to copy.** Both were example workflow files
  under `examples/workflows/`; the binary and the desktop app now carry them beside `default`. `octoflow workflows`
  lists all three as built in, the app's run form offers them, and `octoflow workflows quick` prints one as a file to
  start a variant of your own from. `examples/` is gone, `spec-build-review.toml` with it: it was the built-in
  `default` as a file, which `octoflow workflows default` prints.

- **A workflow file named `quick.toml` or `product-team.toml` no longer loads.** A file cannot take a built-in
  workflow's name. If you copied one from the examples into `~/.config/octoflow-ai/workflows/`, `octoflow workflows`
  now lists it with an error, and `--workflow quick` runs the built-in. Delete the file to run the built-in, or rename
  it (say `my-quick.toml`) to keep your version and run it as `--workflow my-quick`.

  A run started from such a file before this release saved its workflow's definition, and resumes with that
  definition as before.
