## A stopped app run's log no longer points at herdr

A run the desktop app started and that was stopped, as by the close dialog's **Stop all**, ended its `run.log` with
"the role agents keep running in herdr" and an `octoflow resume` command. Neither held: its agents were ended with it,
and the command line refuses to resume the app's runs. The line now reads "interrupted; the role agents were ended;
resume the run from the desktop app". A run whose agents run in herdr is told as before.
