## The Builder leaves the quality gate to the orchestrator

In a run with the quality gate, the Builder used to run the gate itself, several times a turn, and ran out of time
before writing the report the gate waits for. Every prompt of the gated step now ends with a note: the orchestrator
runs the gate once the report is written, so the Builder runs only the tests its change touches, and its turn may
take at most the run's turn timeout. A run without the gate, and a step paced by a human, get no note. A workflow's
own prompt file can replace the note, as it can the note on BLOCKED reports.
