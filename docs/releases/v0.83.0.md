## The app deletes closed runs

- **"Delete closed runs…" in the app.** Beside "Show closed runs" while some run is closed, it lists by task the
  closed runs `orchestrator forget --all` would delete, and counts those still waiting for `prune` to delete their
  branch. Delete deletes them, keeping their metrics, and shows how each went; the overview and the closed runs'
  count then drop them.
- **`serve` answers `POST /forget`.** With `{"dry_run": true}` it says what `forget --all` would do with each run of
  the project; with `{"forget": ["RUN", ...]}` it forgets those runs, each only while `forget` may still delete it.
