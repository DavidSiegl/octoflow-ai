## The docs check needs no Python

Nothing the orchestrator or the desktop app does changes. For those working on Octoflow AI:

- **The docs check is a Rust test,** `cargo test -p octoflow-e2e --test docs`, and `tests/test_docs.py` is gone. It
  checks what the Python test did: each command the docs run takes the flags they give it, the README's flag table
  names every flag and the commands that take it, every name the docs give exists, and every relative link and its
  anchor resolve. Each failure is given as `file:line: what`.
- **Names are read by parsing the code** (syn, a dev-dependency at the version `Cargo.lock` already held), not by
  pattern, so a name that appears only in a comment no longer counts as existing.
