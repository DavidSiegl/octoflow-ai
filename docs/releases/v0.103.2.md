## Two forgets of one project no longer race

`octoflow forget` and the desktop app's forget could run over one project at once from separate processes (two
apps, or the app and the command line), and both delete the same run and archive its metrics twice. Every forget
that deletes now holds a lock file in the project's `.octoflow-ai` directory while it works; another waits for it
(the command line says so once). A lock left by a process that died is taken over: at once when it was this
machine's, after ten minutes when another machine's. A dry run takes no lock.
