## The quality gate leaves this repository

- **`gate.py` is gone from octoflow.** The quality gate is [octoflow-gate](https://github.com/DavidSiegl/octoflow-gate),
  a project of its own; Jenkins already judged this repository's changes with the release `ci/gate.pin` names, and
  now `gate.py`, its Rust helper `ci/gate-rust/` and their tests are removed here. Nothing changes for a run: the
  engine reads the gate's report as before.
- **`orchestrator run --help` names the gate.** `--quality-gate`'s help says the Jenkins job judges the change with
  octoflow-gate rather than `gate.py`.
- **Fewer development dependencies.** Hypothesis, mutmut and pytest-cov left the `dev` group, which only the gate's
  own tests and checks needed.
