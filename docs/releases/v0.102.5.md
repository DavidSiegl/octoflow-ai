## The open handoff file shows a rewrite made within the second it was read

The desktop app reads the handoff file it shows again when the file's modification time changes. That time counts
whole seconds, so a file the agent wrote again within the second of the app's last read kept its time, and the app
kept showing the older, sometimes half-written, text. The app now also reads a file again when its size changes. A
rewrite within the same second that leaves the size the same is still missed until the next one.
