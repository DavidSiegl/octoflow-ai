## A run file that goes away while serve lists it is no problem

- **serve's event stream no longer reports a problem for a file removed while it lists a run.** The listings of a
  run's files and states test each entry and then stat (and read) it; a file renamed or removed in between — the
  secret scan's `leaks-publish.json`, a handoff renamed to its blocked name — failed the whole listing, and the poll
  sent a `problem` event. Such an entry is now left out of that listing. A file still there that cannot be stat'ed or
  read is still an error.
