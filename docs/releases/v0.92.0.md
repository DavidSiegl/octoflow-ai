## You are always asked at a human-paced step, even in the last round

A verdict step that waits for you, such as `design`'s acceptance, is now asked in every round, the last included.
This replaces what the 0.86.0 notes said about `--max-rounds`:

- In round `--max-rounds`, a step that is not human-paced no longer publishes when it asks for changes. In `design`,
  a Design Critic that still asks for changes in the last round sends the run on to your acceptance, and the Creative
  Director tells you what the Critic's review says rather than that it approved.
- Changes you ask for at a human-paced step in the last round are made: the run gets one more round and goes back to
  the step's loop target, as in an earlier round. It publishes once you approve.

A run that already reached its last round resumes under the new rule.
