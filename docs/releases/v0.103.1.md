## A resumed done run's late summary or metrics reach the desktop app

A run that stopped after it was done but before it wrote summary.md or metrics.json gets them written when it is
resumed. The desktop app could still miss them: it stops looking for a finished run's files once they have settled,
and looks again only when the run's state.json is saved, which that resume did not do. The resume now saves it
after the files, keeping the run's record as it was, so the app shows them.
