## The engine can drive agents over the Agent Client Protocol

The engine gains a second agent backend that runs each agent as a child process speaking the
[Agent Client Protocol](https://agentclientprotocol.com) (ACP) over stdio, for agy and opencode, with token counts
taken from the agents' prompt responses. A run on it is saved as state format 3, which earlier releases refuse. Nothing
starts such a run yet: the desktop app will, in a later release. The CLI and the app run their agents in herdr as
before.
