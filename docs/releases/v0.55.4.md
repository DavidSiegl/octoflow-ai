## Tests that run a script they wrote no longer fail with "Text file busy"

Nothing changes for users of the orchestrator or the desktop app; this release carries a fix to tests.

- **A test's executable script is written by a child process.** The desktop shell's
  `serves_a_bundled_binary_without_a_project` failed now and then with "Text file busy (os error 26)": another test
  thread's fork inherited the script's open write descriptor until it exec'd, and the kernel refuses to execute a
  file open for writing. The engine's script-writing test helpers wrote theirs the same way and change alike.
