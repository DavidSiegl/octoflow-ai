## The quality gate is octoflow-gate 0.10.0

- **A base without `ci/gate.pin` is judged by octoflow-gate 0.10.0**, not 0.7.0, and `/setup/gate` writes a pin
  naming 0.10.0. That release adds a check for a new dependency cycle between a project's modules, which fails the
  gate; its [docs](https://github.com/DavidSiegl/octoflow-gate/blob/v0.10.0/docs/quality-gate.md) say how it reads
  Rust and Python imports and which files a project can exempt. A base that pins a release judges by that release,
  as before.
- **Its quality file and quality.json are read as 0.7.0's were**: the schema is still version 1, and the release's
  golden reports are byte for byte 0.7.0's.
- **This repository is judged by 0.10.0 too**: `ci/gate.pin` names it.
