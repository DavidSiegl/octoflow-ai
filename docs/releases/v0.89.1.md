## The schema-version error names the pin

When a quality round's `quality.json` has a `schema_version` this engine does not read, the error no longer tells you
to change a Jenkins quality job, which octoflow has not used since 0.71.0. It now says the release the run's base
pins in `ci/gate.pin` wrote the report, and that you can pin a release that writes the version this engine reads, or
use an octoflow that reads the other.
