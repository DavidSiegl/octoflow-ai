## A new run no longer deletes the branch it is about to start from

A run that opens a pull request first deletes the branches of earlier runs whose pull request is done. When the project
had a closed run's branch checked out, its pull request merged, that sweep deleted the branch on `origin`, and the run
then refused it as a branch "which origin does not have". The sweep a starting `run` or `drain` makes now leaves the
branch checked out in the project alone, and the run takes it as its base. `octoflow prune` deletes it as before.

## A long first word no longer leaves a commit title of one short word

A title over 72 characters is cut at its last blank that fits, then "…". A task such as `Fix https://example.com/…`
with a long URL was therefore titled "Fix…". When that cut would keep fewer than 36 characters, the title is now cut
inside the long word, at 71 characters and "…", as a title with no blank is.

## The app's turn feed shows how long a turn waited

The run map's turn feed showed only a turn's whole length, so a turn that spent most of it waiting looked slow. An
ended turn now says how much of its length its waits took, as `summary.md` does: "15m (3m waiting for you, 6m
waiting outside the run)".
