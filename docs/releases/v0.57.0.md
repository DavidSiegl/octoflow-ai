## An agent and a model for each role in the run form

The desktop app's run form has a row for each role of the workflow you pick, in the workflow's order, with its own
agent and model.

- **A row left empty** falls back as on the CLI: to the agent and model you gave for the whole run, else to the
  role's default. The form shows that fallback greyed in the row, "(the run's)" or "(default)".
- **A row you fill in** becomes the run's `--role-agent` or `--role-model` for that role, which overrides
  `--agent` and `--model`.
- **Picking another workflow** rebuilds the rows: a role the new workflow also has keeps what you entered for it, and
  the others start empty.
