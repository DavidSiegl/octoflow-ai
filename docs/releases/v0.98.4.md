## The .deb recommends bash-completion, which bash's Tab completion needs

The `.deb` now recommends the `bash-completion` package, so `apt install ./<file>.deb` installs it unless recommends
are turned off; bash reads the completion script the `.deb` installs only through that package's loader, so without
it Tab after `octoflow` completed nothing in bash. zsh and fish need nothing more. Root's `~/.bashrc` in a Debian
container does not load bash-completion; the README gives the line to add there.
