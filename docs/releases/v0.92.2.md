## Overlapping forget requests to one `octoflow serve` forget a run once

`octoflow serve` now handles two POST /forget requests that list the same finished run at the same moment one after
the other: the first forgets it and the second finds it already gone, so the run is reported forgotten once and its
metrics are archived once instead of twice. This holds when the two requests name the project's folder differently
as `~/proj` and `/home/you/proj/`; a path through a symlink still counts as another project. The desktop app sends
one forget at a time, so nothing changes in its use. Two app instances, or `octoflow forget` from a shell, forgetting
the same run at once are not covered yet.
