## The product-team workflow has the Product Manager accept the change

- **The `product-team` example workflow has the Product Manager accept the change** once the Tech Lead approves it.
  The Product Manager's agent, the one that ran the interview when the run had one and its session is still there,
  judges the change against the requirements' acceptance criteria and success measures alone, in business terms, and
  writes `acceptance-{n}.md`. A request for changes from either goes back to the Engineer, whose prompt for the next
  round names the file that sent it back. The Tech Lead's review no longer opens with a summary for the Product
  Manager.
