## A resume prompts an agent its stopped run never got to prompt

- **A run stopped while an agent's harness asked something before starting** (Claude Code's folder-trust question,
  say) no longer has its step prompt typed into that dialog on resume. The resume asks you to answer the dialog in the
  pane, waits for it, then prompts the agent.
- **A run stopped right after relaunching an exited agent into its session**, before the prompt to continue went
  out, no longer leaves that agent idle until the stall notice: the resume sends it the prompt to continue.

`state.json` keeps an agent's `"unprompted"` mark (`new`, `resumed` or `restarted`) until the agent takes its first
prompt. A run saved by an older engine resumes as before.
