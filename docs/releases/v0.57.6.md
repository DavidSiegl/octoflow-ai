## The desktop app shows the project's logo

- **The top bar starts with the logo** and the name "Octoflow AI", at the bar's height, before the project folder and
  machine fields; at a narrow window the fields wrap below them. The image's accessible name is the logo's own title.
- **The page names the logo as its icon,** so a browser tab showing the app (`vite dev`, or `serve`'s page) shows it.

For those working on Octoflow AI: the page serves `ui/public/logo.svg`, a copy of `docs/logo.svg`, because Vite's dev
server refuses files outside `ui/` and `index.html`'s icon link cannot point there; `ui/src/logo.test.tsx` holds the
two equal byte for byte, so `docs/logo.svg` stays the one to edit.
