## The desktop app names its npm packages' licenses

- **The desktop app now ships the license texts of the npm packages its window holds,** React, react-markdown and
  every other package of `ui/package-lock.json`'s production tree, plus Vite and Rolldown, whose code the built
  bundle contains. The app has them among its resources as `THIRD-PARTY-LICENSES-NPM.html`, beside the crates'
  `THIRD-PARTY-LICENSES.html`, and each release has them as `octoflow-desktop-npm-licenses.html`.
- **A package under a license `packaging/about.toml` does not accept fails the desktop build,** before the long
  part of it, as a crate under one fails `packaging/build-binary.sh`.
