## The command is octoflow

- **The engine's binary is `octoflow`**, as the release assets and the desktop app already were:
  `cargo build --release --locked -p octoflow-engine` now builds `target/release/octoflow`, and `--help` and error
  messages call the command `octoflow`. A build copied onto your `PATH` as `orchestrator` keeps working under that name
  until you replace it. Install the new one as `octoflow`, and leave `orchestrator` a link to it while a `serve` or a
  run started by the old name is still going: `serve` starts new runs by the path it was started from, and a run's
  resume hint names the command it was started as.

  ```sh
  cargo build --release --locked -p octoflow-engine
  install -m 755 target/release/octoflow ~/.local/bin/octoflow
  ln -sf octoflow ~/.local/bin/orchestrator   # remove it once nothing started as orchestrator is running
  ```

- **A run's commit trailers are `Octoflow-Run`, `Octoflow-Workflow`, `Octoflow-Role` and `Octoflow-Gate`**, replacing
  `Orchestrator-*`. Commits made before keep their old trailers; nothing reads them back.
