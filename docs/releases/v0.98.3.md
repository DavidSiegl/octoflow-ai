## ACP adapter installs: the previous install stays, a leftover is a warning, and the install runs in the background

Installing an ACP adapter from the desktop app's setup dialog now keeps the install of the previous pins, so a run
started by an older engine before the upgrade still finds its agent; only older installs are removed. An install that
is in place succeeds even when removing an old one fails: the dialog shows that as a warning, and the next install
removes what is left. The install also runs in the background: the dialog shows "Installing…" until it ends, also
when it is closed and opened again meanwhile, and then the error or the warning.
