## An ACP run's agent tab is a conversation (behind the developer switch)

With `OCTOFLOW_APP_BACKEND=acp` in serve's environment, a hidden developer setting, the agent tab of a run the app
started over ACP shows the agent's conversation from its journal: what it says, its thoughts (collapsed), its tool
calls with their status, and its permission requests, each answered with a button. Whenever the run waits on you
(the interview, a BLOCKED report's question, an agent idle without writing its file) the tab has a message box,
whose message is the agent's next prompt. A run that is not running shows its conversation read-only.

Such a run shows its own desktop notifications, by `notify-send` on Linux and `osascript` on macOS, whether the app
is open or not; a missing command is logged once and the run goes on.

serve gains `GET /agent/events`, `POST /agent/answer` and `POST /agent/message` for runs over ACP, and run records
gain `backend` (`herdr` or `acp`). Without the setting nothing changes: runs in herdr keep their pane view.
