## A resumed agent's turn is counted in the session it runs in

- **An agent `resume` finds still running has its turn recorded in its session.** An orchestrator that stopped
  between starting an agent and saving its session left the agent's record without one; `resume` found the agent
  alive and prompted it, and the turn ended with no session, so `metrics.json` gave its tokens as `unknown`. Now
  `resume` asks herdr for every agent it finds alive and saves the session herdr reports, so the turn is recorded in
  it and its tokens are counted. The same goes for an agent that moved to a new session while no orchestrator
  watched it: its turn is recorded in the new one, not the saved one. Asking herdr costs no call more than before.
