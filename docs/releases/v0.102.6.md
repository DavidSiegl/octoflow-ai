## summary.md, the pull request and metrics.json name the model a role actually ran on

When an ACP harness's session did not offer the model a role asked for, the agent ran on another one, but summary.md's
roles table, the `Octoflow-Role` commit trailer (and the pull request's table of them) and metrics.json's `roles` still
named the model asked for, and a turn that ran on the harness's default read `default` as if no model had been asked
for. They now name the model the agent ran on and the one it was not offered: `sonnet (opus not offered)`, or
`default (o3 not offered)` when the session named none it took instead. metrics.json's `roles` give the model ran on
as `model`, and its `roles` and `turns` gain `unoffered_model` where there is one.
