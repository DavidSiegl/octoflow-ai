## The workflow editor no longer edits three workflow settings

- **The desktop app's workflow editor no longer shows `max_files`, `max_lines` and `proof_command`.** They tune the
  quality gate's diff budget and the command that runs a reviewer's proofs, which few workflows change, and as bare
  inputs they said nothing about what they do. Set them in the workflow file by hand: `proof_command` as the
  README's "Your own workflows" describes, the diff budget as `docs/quality-gate.md` does. A file that sets them
  keeps them when the editor saves it, and so does a copy made with Duplicate…. While no step of the workflow loops
  back, a save leaves `proof_command` out, since there are no proofs for it to run, and writes it again once a step
  does.
