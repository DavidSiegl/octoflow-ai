## The workflow editor drops three settings

- **The desktop app's workflow editor no longer shows `max_files`, `max_lines` and `proof_command`.** They tune the
  quality gate's diff budget and the command that runs a reviewer's proofs, which few workflows change, and as bare
  inputs they said nothing about what they do. Set them in the workflow file by hand, as the README describes. A
  file that sets them keeps them when the editor saves it, and so does a copy made with Duplicate….
