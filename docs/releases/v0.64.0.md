## The desktop app starts herdr when it is not running

- **Start no longer needs a herdr server running.** When the app, or `orchestrator serve`, starts a run and no herdr
  server is running on this computer, it starts one without a window, as the herdr session `octoflow`, and the run
  goes there. The server stays up after the app closes, and later runs share it. `herdr session attach octoflow`
  shows it in a terminal; `herdr session stop octoflow` ends it and the runs in it. With your own herdr running, runs
  start there as before. `POST /run` no longer answers 502 `no herdr server here; start herdr`; it answers 502
  `cannot start a herdr server: …` when the session's server does not come up within 15 seconds.
