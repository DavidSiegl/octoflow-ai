## `octoflow resume` resumes a run whose state records an empty `closed`

A run whose `state.json` has an empty `closed` is not closed: `octoflow close`, `octoflow forget`, `octoflow list` and
`octoflow drain` already treated it so, but `octoflow resume` refused it as closed. It now resumes it. The rule lives
in one place now, so the commands can no longer disagree about it.
