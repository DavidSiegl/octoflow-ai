## A run's agent and turn records are read field by field

- **A run saved by this format reads, resumes, lists and shows as before.** Its agents' and turns' records are now
  read field by field, rather than looked up by key wherever used, so every reader of a role's harness gives one
  answer: its agent's, else the one its next agent starts in, else `claude`.
- **A `state.json` whose agent or turn record, or proof run, lacks a field this format always writes is refused**
  as invalid, naming the field, as one missing a field of the run's own is. Before, an agent or turn record without
  its harness was read as `claude`'s, and a proof run without the round that wrote it as a first run: shapes only a
  release before the current state format wrote, whose runs are already refused (finish or close them with that
  release).
