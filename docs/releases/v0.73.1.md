## The engine's source and docs describe it as it is

Nothing a user runs or saves changes. The engine's source comments, its test names and the docs no longer describe
the engine as a port of an earlier one, or its behaviour by comparison with that one; each states what the code does.

- **docs/ui-options.md is gone**: the assessment that chose a Tauri desktop app, written about a window that no
  longer exists. `docs/architecture.md` says in one sentence why the app is Tauri.
