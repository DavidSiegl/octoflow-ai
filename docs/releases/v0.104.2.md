## A resume that changes a role's model no longer renames its running agent's model

When `resume --role-model ROLE=MODEL` gave a role a new model while that role's agent was still running, the agent
kept the model it started on. But summary.md's roles table, the `Octoflow-Role` commit trailer, metrics.json's
`roles.<role>.model` and every later turn record named the new one. Each agent's record in `state.json` now keeps the
model it was started on, and the run names that one. The resume's model applies to the role's next agent. A run saved
by an earlier release names the role's model as before until its agent restarts.
