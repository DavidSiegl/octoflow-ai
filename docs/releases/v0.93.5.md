## The app installs claude's ACP adapter (behind the developer switch)

With `OCTOFLOW_APP_BACKEND=acp` in serve's environment, a hidden developer setting, the app's claude runs start
claude's ACP adapter, `@agentclientprotocol/claude-agent-acp` 0.101.0, on Node 22.23.4, in place of the claude CLI.
The setup dialog offers "Install claude's ACP adapter (about 913 MB)" until it is installed: it downloads Node,
checks it against the sha256 octoflow carries for it, and installs the adapter and its dependencies with that Node's
npm from a lockfile octoflow carries, every package checked against its integrity hash and none running an install
script. The install goes in octoflow's data directory (`$XDG_DATA_HOME/octoflow-ai/claude-acp`, else
`~/.local/share/octoflow-ai/claude-acp`); a later octoflow with other pins installs anew and removes the old one. A
claude run without it fails, naming the setup dialog. Runs in herdr are unchanged.

serve gains `POST /setup/claude`, and `/setup` answers `claude_install`.
