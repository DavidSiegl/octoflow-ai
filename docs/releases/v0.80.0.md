## Edit… and New… in the run form

- **The run form's Workflow** has "Edit…" under it, which opens the workflow editor on the workflow picked
  (read-only for a built-in one, with Duplicate…), and "New…", which opens it on a copy of `default`. After a save
  the form reads the workflows again and picks the one saved, if it loads, rebuilding its roles' rows: a role the
  workflow had before keeps the agent and model its row was given. The form waits while the editor is open, and
  Edit… and New… are off while the run is starting.
